# Phase 5 validation contract

Base: production-v3-phase4-ml-governance

This phase owns operational reliability and observability.

Validation requirements:
- SLOs and alert rules are machine-validated.
- Dashboard provisioning is checked.
- Dependency failure modes are exercised.
- Metrics cardinality stays bounded.
- Logs/traces contain no secrets.
- Previous-phase CI and integration tests stay green.
